## 方案A：复杂场景500米方案A

方案A用于板1、板2的白天复杂背景场景。核心思路是先进行边缘分割，将下方建筑、树木等高纹理背景区域整体屏蔽，只保留上方天空区域进入白天高层检测链路。

运行逻辑：

1. 采集2K画面，帧差计算使用 `1920x1080`。
2. 对当前灰度图或静态背景图做 Canny 边缘与局部边缘密度分析。
3. 根据边缘密集区域生成下方建筑/树木屏蔽区，并从边缘线向下整片填充。
4. 屏蔽区不再运行低层检测，也不送入 YOLO。
5. 屏蔽区上方的天空区域使用白天高层500米检测参数。
6. 回传画面可显示青色半透明屏蔽区、白色ROI框、红色YOLO命中框和绿色确认框。

关键参数：

```text
UAV_SCENE_MODE=day
UAV_LAYER_MODE=high
UAV_CAPTURE_W=2560
UAV_CAPTURE_H=1440
UAV_DIFF_W=1920
UAV_DIFF_H=1080
UAV_PROCESS_EVERY_N_FRAMES=3
UAV_EDGE_REGION_LAYER=1
UAV_EDGE_REGION_SUPPRESS_LOW=1
UAV_EDGE_REGION_FILL_BELOW=1
UAV_EDGE_REGION_DRAW_MASK=1
UAV_RKNN_MODEL=/home/Tronlong/rknn_model_zoo/examples/yolov5/model/yolov5s_day_20260626.rknn
```

## 方案B：白天500米高层方案B

方案B用于板3到板9的白天高层天空场景。该方案沿用已验证的白天高层远距离检测链路，以白天6月26号模型为基准，保留悬停保持和轨迹确认能力。

运行逻辑：

1. 采集2K画面，帧差计算使用 `1920x1080`。
2. 基于帧差生成天空小目标ROI。
3. 将ROI送入白天模型推理。
4. 通过近期命中、轨迹分数、静态悬停确认等规则输出绿色确认框。
5. 不启用复杂背景下方屏蔽，不启用夜间160 ROI放大。

关键参数：

```text
UAV_SCENE_MODE=day
UAV_LAYER_MODE=high
UAV_CAPTURE_W=2560
UAV_CAPTURE_H=1440
UAV_DIFF_W=1920
UAV_DIFF_H=1080
UAV_PROCESS_EVERY_N_FRAMES=3
UAV_HOVER_HOLD=1
UAV_EDGE_REGION_LAYER=0
UAV_RKNN_MODEL=/home/Tronlong/rknn_model_zoo/examples/yolov5/model/yolov5s_day_20260626.rknn
```

## 方案C：夜间400米方案C

方案C用于板1到板9的夜间高层场景。该方案使用夜间最新模型，输入降为 `640x480`，只在帧差产生运动点时裁剪 `160x160` 小ROI并放大送检，避免夜间全帧兜底带来的延迟和误检。

运行逻辑：

1. 夜间摄像头输入使用 `640x480`。
2. 帧差计算同样使用 `640x480`。
3. 仅当帧差出现运动点时生成 `160x160` 运动ROI。
4. 将运动ROI放大到模型输入后进行推理。
5. 关闭全帧兜底、轨迹搜索ROI和白天悬停保持。
6. 开启夜间静止亮点/暗点屏蔽，降低星点、固定灯点误检。

关键参数：

```text
UAV_SCENE_MODE=night
UAV_LAYER_MODE=high
UAV_CAPTURE_W=640
UAV_CAPTURE_H=480
UAV_DIFF_W=640
UAV_DIFF_H=480
UAV_PROCESS_EVERY_N_FRAMES=2
UAV_MOTION_ZOOM_CROP_SIZE=160
UAV_MOTION_ZOOM_MAX_ROIS=1
UAV_MOTION_ZOOM_ONLY=1
UAV_TRACK_SEARCH_ROIS=0
UAV_HOVER_HOLD=0
UAV_FULLFRAME_SEARCH_FALLBACK=0
UAV_NIGHT_STATIC_POINT_SUPPRESS=1
UAV_RKNN_MODEL=/home/Tronlong/rknn_model_zoo/examples/yolov5/model/yolov5s_night_latest.rknn
```

## 现场切换原则

1. 板1、板2白天使用方案A，夜间使用方案C。
2. 板3到板9白天使用方案B，夜间使用方案C。
3. 白天模型统一使用 `yolov5s_day_20260626.rknn`。
4. 夜间模型统一使用 `yolov5s_night_latest.rknn`。
5. 切换后以 `systemctl show python_autostar.service -p Environment` 核对 `UAV_SCENE_MODE`、`UAV_RKNN_MODEL`、输入分辨率和关键开关。
