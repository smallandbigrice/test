# 方案 ABC 桌面切换入口

## 使用顺序

1. 确认电脑和板端在同一网段。
2. 双击对应 `.bat` 脚本。
3. 等待脚本写入 systemd drop-in、执行 `daemon-reload` 并重启 `python_autostar.service`。
4. 在接收端查看视频画面和检测状态。

## 脚本说明

| 脚本 | 板端范围 | 模式 |
|---|---|---|
| `一键切换_方案A_复杂场景500米_板1板2.bat` | 板1、板2 | 复杂背景 500 米 |
| `一键切换_方案B_白天高层500米_板3到板9.bat` | 板3到板9 | 白天高层 500 米 |
| `一键切换_方案C_夜间无光全场景检测_板1到板9.bat` | 板1到板9 | 夜间无光全场景检测 |
| `打开接收端_640x480.bat` | 本地电脑 | 打开 640x480 视频接收端 |

## 模型来源

模型封档路径：

`E:\detect uav\scheme_ABC\models`

- 白天模型：`yolov5s_day_20260626.rknn`
- 夜间无光全场景模型：`yolov5s_night_latest.rknn`

日常一键切换不重复上传模型；需要重传模型时，直接调用 PowerShell 脚本并显式增加部署参数。

## 接收端

接收端入口：

`E:\detect uav\scheme_ABC\scripts\desktop_wrappers\打开接收端_640x480.bat`

需要查看低码率多路回传时，优先使用该接收端。
